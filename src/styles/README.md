# src/styles/ — estilo «Cuaderno»

`global.css` es el único archivo de estilos: importa Tailwind y el plugin de tipografía, declara los tokens
con `@theme` (colores, fuentes, radio de 12 px, sombra desplazada), los patrones de las portadas y el ajuste
del texto de lecciones (`prose`). La paleta de Tailwind está borrada: solo existen los colores de Pista.

Cambiar un color aquí cambia todo el sitio. Si cambias uno, vuelve a medir su contraste (mínimo 4,5:1).
